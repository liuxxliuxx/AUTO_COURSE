# 智慧树自动刷课

自动播放智慧树平台课程视频，支持弹题测验自动答题、验证码人工介入、多课程刷课和时长限制。

## 安装

```bash
pip install -r requirements.txt
```

需要 Chrome 浏览器。chromedriver 会自动通过 webdriver-manager 下载，如果系统已有 chromedriver 则优先使用。

## 运行

```bash
python main.py
```

启动后通过 GUI 配置账号、课程 URL 和刷课时长。

## 登录方式

- **智慧树直接登录** — 手机号 + 密码，自动处理滑块验证码
- **数字石大 (UPC) SSO** — 通过统一认证登录，Vue 组件注入凭据

验证码弹出时需在浏览器中手动完成，完成后点击 GUI 的"确认验证码已完成"继续。

## 功能

- 自动识别未完成课程视频并逐个播放
- 弹题测验随机选择答案并关闭
- 学前必读弹窗自动关闭
- 视频暂停自动恢复播放
- 刷课时长上限设置
- 账号密码通过系统 keyring 安全存储
- URL 历史记录自动保存
