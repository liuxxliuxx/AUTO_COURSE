# 应用图标

蓝绿色书页与播放箭头，用户于 2026-10-04 确认方向。`icon-source.png` 是 imagegen 生成的透明原图；所有平台资源由这一来源转换。

- `icon.png`：1024 × 1024 RGBA。
- `icon.ico`：16 / 24 / 32 / 48 / 64 / 128 / 256 像素。
- `icon.icns`：macOS 原生资源。
- `icons/`：各尺寸 PNG，可用于后续文档和网页。

更新：安装 Pillow 后运行 `python3 scripts/build-icons.py`。保持外部透明边距和居中构图。不得把图标预览截图用作构建来源。
