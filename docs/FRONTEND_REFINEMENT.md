# 前端舒适度与操作体验优化

## 前一版诊断

- 36px 双行列表与 28px 控件挤压中文文字；名称、辅助信息的距离不足。
- 普通行几乎都有边框，详情也到处有分隔线，视觉噪声大。
- 辅助文字、边框、背景都有较明显的冷蓝色；主按钮又是浅蓝色，主次不够明确。
- 左栏、页头、内容列表从顶部连续铺开，边缘留白不足。
- 工作台对每一步重复显示三个边框按钮；顺序内容与动作容易相互挤压。
- 小窗口将步骤与配置完全互斥，用户改配置时看不到执行顺序。
- 课程主要操作在详情底部，长地址或说明可能将其推离首屏。

## 本轮采用的设计基线

- 正文 13px；辅助 12px；页面标题 18px；详情名称 17px。中文行高 1.5。
- 主控件 32px；普通双行列表最小 48px；主导航 36px。
- 固定浅白内容、低饱和背景、深中性色正文；蓝色只用于主按钮、焦点、进度及选中态。
- 内容内边距 16–20px，分组间距 16–20px；只在主要分区保留细线。
- 日常操作直接在详情顶部；减少一页内重复的配置与提示。
- 工作流保留专用工作台，优先在普通笔记本尺寸中同时显示步骤与配置；移动尺寸采用连续滚动的直接编辑布局。
- 不添加渐变、弹跳、缩放、入场动效；只使用约 100ms 的颜色过渡，并尊重减少动态效果设置。
