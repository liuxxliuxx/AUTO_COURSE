# AUTO_COURSE 2.0 用户指南

文档以 Markdown 保存在仓库中。应用「关于与帮助 → 打开用户文档」和帮助菜单的「用户文档」会使用默认浏览器打开仓库的 `docs/` 目录，需要联网阅读。

## 安装

仅支持 Windows x64 和 macOS 13 及以上（Apple Silicon / Intel）。从官方仓库 Releases 下载对应架构，比较同一 Release 的 SHA256SUMS.txt；Windows 安装包是 `AUTO_COURSE-<版本>-win-x64.exe`，Mac 为 `AUTO_COURSE-<版本>-mac-<架构>.dmg`。

Windows：运行安装向导，可选择安装目录并创建桌面或开始菜单快捷方式。如出现 SmartScreen 提示，先核对来源与校验值，按组织或系统的安全策略处理。Mac：打开 DMG，将 AUTO_COURSE 拖入 Applications 后启动。当前未签名、公证；如系统拦截，可查看「系统设置 → 隐私与安全性」的应用打开选项。若提示文件损坏或架构不支持，请重新下载并核对校验值和架构；不建议关闭系统全局安全保护。

普通学习不需要 Node、Python 或 ChromeDriver。系统版本要求以当前打包 Electron 的支持范围及 Release 实测记录为准；不承诺尚未测试的旧系统。

## 快速上手

1. 进入「设置 → 账号与登录」，选择智慧树、机构 SSO 或旧门户。输入账号密码并保存；更改账号时需重新输入密码。仅旧门户流程使用登录跳转 URL。
2. 在「课程」点击添加课程，粘贴实际课程学习页地址、填写课程名称，选择课程类型与运行方式。
3. 根据需要设置起始位置、续学、跳过已完成与单次时长。保存只建立课程，不会立即运行。
4. 选中课程，点击开始运行，在「运行」页查看任务与日志。
5. 登录或验证码需人工处理时，打开对应课程窗口，完成后点击继续。登录失败不会自动切换另一种登录方式。
6. 要修改或删除正在运行的课程，先停止对应任务。

## 课程与工作流

| 运行方式 | 传统课程 | 图谱课程 | 掌握度课程 |
| --- | --- | --- | --- |
| 学习 | 支持 | 支持 | 支持 |
| 学习并转录 | 支持 | 支持 | 不支持 |
| 仅转录 | 支持 | 不支持 | 不支持 |

课程默认配置只影响新课程。掌握度课程会保存确认过的正确答案与试错记录；课程详情可导出题库 JSON。

在工作流页添加多个课程步骤并保存；每一步保存自己的运行方式与配置。保存不启动。可立即运行，或设置单次、每日定时与时区。应用运行时检查定时；错过后补跑最近一次，课程冲突时拒绝启动。应用关闭、系统休眠时无法保证准时执行，定时不是系统唤醒任务。

不同工作流可并行；同一课程不能同时执行。编辑工作流只影响下一次启动，不改正在执行的快照。退出时未完成实例记为中断，重新启动不会自动续跑这些实例。

## 转录（可选）

仅使用学习功能可跳过这一节。转录需要系统 PATH 能找到 ffmpeg 和 Python，另外安装 `python/transcriber/requirements.txt` 中的 funasr、modelscope、torch 与 torchaudio。完整源码中的安装命令：

```sh
pip install -r python/transcriber/requirements.txt
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
```

首次使用会下载 SenseVoiceSmall 模型（数百 MB），需可用网络与磁盘空间。在设置 → 转录选择输出位置，结果为 `课程录音/<课程名>/<课时名>.txt`；同名课程附加序号隔离目录。失败时查看运行日志，检查模型下载、ffmpeg、Python 和依赖安装是否处于同一可用环境。

## FAQ

**保存课程后为什么不运行？** 保存与启动是两个操作，选中课程后点击开始运行。

**为什么提示课程冲突？** 另一任务已占用这门课程，停止它或修改新工作流的课程集合。

**修改默认配置为何没有改变旧课程？** 默认配置只用于新课程；修改已有课程请进入课程详情。

**为什么仍需手动登录或验证码？** 自动化不能保证所有登录场景都可用，按运行页提示在课程窗口完成并继续。

**是否自动更新？** 当前没有自动下载安装更新。「查看发布版本」会打开官方 Releases；请手动下载升级并保留数据。

**能否直接拷贝密码文件换电脑？** 凭据依赖系统加密环境，不能保证跨机器解密；换电脑后重新输入账号密码。

## 故障排除

- 无法启动：确认架构、下载完整性、安全拦截以及是否已有实例；重新启动后仍失败，反馈系统版本和出现错误的步骤。
- 登录失败：检查登录方式、账号、密码和旧门户 URL；三条路径不自动回退，失败页面会保留以便检查。
- 课程地址被拒绝：粘贴学习页而非首页或分享链接，并确认课程类型。
- 任务卡住：查看运行页是否等待人工处理；完成页面操作后点击继续。如是普通执行错误，停止后根据日志修正配置再运行。
- 转录失败：核对 ffmpeg、Python、模型下载网络、磁盘空间以及输出目录写权限。
- 定时未启动：检查规则是否启用、时区和时间、应用是否运行，以及课程是否冲突。
- 界面或页面改版问题：通过「关于与帮助」复制诊断信息并打开反馈页，附上复现步骤、错误提示和必要日志。截图与日志发送前检查账号、课程地址和个人信息。

诊断信息只包含版本、构建编号、运行环境、数据库 schema 与加密可用性，不包含账号密码、课程列表、浏览器登录态或用户目录。应用不自动上传诊断信息。

## v1 → v2 迁移与备份

升级前退出 v1/v2 并备份数据目录。v1 数据库自动检测位置：

- Mac：`~/Library/Application Support/zhihuishu_auto_course/course_progress.db`
- Windows：`%APPDATA%\zhihuishu_auto_course\course_progress.db`

v2 在数据库为空时只读导入旧设置、课程地址历史与进度；已有 v2 数据不会覆盖。旧密码不会迁移，升级后重新输入。新界面把旧当前课程与地址历史整理为课程库；重复地址合并，多个同名课程造成续学归属不明确时需人工确认。废弃的 Chrome/ChromeDriver 路径与旧背景设置不再使用。

新安装的默认 v2 数据目录：Mac 为 `~/Library/Application Support/auto-course`，Windows 为 `%APPDATA%\auto-course`。若已有旧打包版 `ZhiHuiShu AutoCourse` 目录中的 v2 数据库，则优先继续使用该目录；否则复用 `auto-course`。当两处都存在时优先旧打包目录，不自动合并。实际位置以「打开数据目录」为准。

关闭应用后备份整个用户数据目录（数据库、凭据、浏览器配置）；恢复到同一机器时先退出应用。转录输出目录需另行备份。不要在运行期间直接复制活跃数据库，也不要删除旧版目录来触发重新导入。

回退 v1 可使用冻结的 `v1-pyside-final` 版本及保留的 v1 数据；v2 新增工作流与题库不会反向导入 v1。迁移异常可通过运行日志和技术迁移说明排查；不要覆盖已有 v2 数据库。
