# AUTO_COURSE 3.0 用户指南

文档以 Markdown 保存在仓库中。应用「关于与帮助 → 打开用户文档」和帮助菜单的「用户文档」会使用默认浏览器打开仓库的 `docs/` 目录，需要联网阅读。

## 安装

仅支持 Windows x64 和 macOS 13 及以上（Apple Silicon / Intel）。从官方仓库 Releases 下载对应架构，比较同一 Release 的 SHA256SUMS.txt；Windows 安装包是 `AUTO_COURSE-<版本>-win-x64.exe`，Mac 为 `AUTO_COURSE-<版本>-mac-<架构>.dmg`。

Windows：运行安装向导，可选择安装目录并创建桌面或开始菜单快捷方式。如出现 SmartScreen 提示，先核对来源与校验值，按组织或系统的安全策略处理。Mac：打开 DMG，将 AUTO_COURSE 拖入 Applications 后启动。当前未签名、公证；如系统拦截，可查看「系统设置 → 隐私与安全性」的应用打开选项。若提示文件损坏或架构不支持，请重新下载并核对校验值和架构；不建议关闭系统全局安全保护。

普通学习不需要 Node、Python 或 ChromeDriver。系统版本要求以当前打包 Electron 的支持范围及 Release 实测记录为准；不承诺尚未测试的旧系统。

## 快速上手

1. 进入「账号」，为每个账号填写名称，选择智慧树、机构 SSO 或旧门户，输入登录账号和密码并保存。更改登录账号时需重新输入密码；仅旧门户流程使用登录跳转 URL。
2. 在「课程」点击添加课程，粘贴实际课程学习页地址、填写课程名称，选择课程类型与运行方式。
3. 根据需要设置起始位置、续学、跳过已完成与单次时长。保存只建立课程，不会立即运行。
4. 选中课程，点击「构建工作流」。每一步选择执行账号，保存工作流后点击「立即运行」，在「运行」页查看任务与日志。
5. 登录或验证码需人工处理时，打开对应课程窗口，完成后点击继续。登录失败不会自动切换另一种登录方式。
6. 要修改或删除正在运行的课程，先停止对应任务。

## 课程与工作流

| 运行方式 | 传统课程 | 图谱课程 | 掌握度课程 |
| --- | --- | --- | --- |
| 学习 | 支持 | 支持 | 支持 |
| 学习并转录 | 支持 | 支持 | 不支持 |
| 仅转录 | 支持 | 不支持 | 不支持 |

课程默认配置只影响新课程。掌握度课程会保存确认过的正确答案与试错记录；课程详情可导出题库 JSON。

在工作流页添加多个课程步骤并保存；每一步绑定账号和课程，保存自己的运行方式与配置。只有一个账号时自动选中；多个账号时须明确选择。保存不启动。可立即运行，或设置单次、每日定时与时区。应用运行时检查定时；错过后补跑最近一次，账号冲突时拒绝启动。应用关闭、系统休眠时无法保证准时执行，定时不是系统唤醒任务。

不同账号的工作流可并行，同一门课程也可由不同账号同时执行。工作流启动时占用涉及的全部账号，直到整个运行及资源清理完成才释放；涉及同一账号的其他工作流会被拒绝，不自动排队。编辑工作流只影响下一次启动，不改正在执行的快照。退出时未完成实例记为中断，重新启动不会自动续跑这些实例。

## 转录（可选）

仅使用学习功能可跳过这一节。转录需要系统 PATH 能找到 ffmpeg，无需安装 Python、PyTorch 或 FunASR。应用内置 sherpa-onnx 的 JavaScript/WASM 运行库，模型在独立线程中处理，音频不会上传到云端。

首次使用从 Hugging Face 下载固定版本的 SenseVoiceSmall INT8 模型（约 239 MB）与词表，从 GitHub 下载 Silero VAD 模型，缓存于用户数据目录的 `models/sensevoice-small-int8-2024-07-17/`。下载失败可检查网络后重试；已完整下载的文件会复用。也可预先将 `model.int8.onnx`、`tokens.txt`、`LICENSE`、`silero_vad.onnx` 放入该目录后离线使用。

在设置 → 转录选择输出位置，结果为 `课程录音/<账号名称>-<账号ID>/<课程名称>-<课程ID>/<课时名>.txt`，同名账号和课程也拥有独立目录。长课程按语音活动分段转录，输出按片段换行，并显示处理进度。失败时查看运行日志，检查模型下载网络、ffmpeg、磁盘空间和目录写权限。

## 清理缓存

进入「设置 → 缓存」，点击「清理缓存」，可清除课程网页缓存和应用临时下载文件。需先停止所有任务并等待课程窗口关闭；清理期间暂不启动新任务，定时任务会等待清理结束后继续检查。

清理保留网站登录状态、账号设置、课程进度、题库、转录成品和已下载的 SenseVoice 模型。网页资源会在下次访问时重新加载。

## FAQ

**保存课程后为什么不运行？** 保存与启动是两个操作。选中课程后构建工作流，为步骤选定账号，保存后点击立即运行。

**为什么提示账号冲突？** 另一个工作流已占用此账号，等待其结束、停止它或修改新工作流的账号集合。

**修改默认配置为何没有改变旧课程？** 默认配置只用于新课程；修改已有课程请进入课程详情。

**为什么仍需手动登录或验证码？** 自动化不能保证所有登录场景都可用，按运行页提示在课程窗口完成并继续。

**是否自动更新？** 当前没有自动下载安装更新。「查看发布版本」会打开官方 Releases；请手动下载升级并保留数据。

**能否直接拷贝密码文件换电脑？** 凭据依赖系统加密环境，不能保证跨机器解密；换电脑后重新输入账号密码。

## 故障排除

- 无法启动：确认架构、下载完整性、安全拦截以及是否已有实例；重新启动后仍失败，反馈系统版本和出现错误的步骤。
- 登录失败：检查登录方式、账号、密码和旧门户 URL；三条路径不自动回退，失败页面会保留以便检查。
- 课程地址被拒绝：粘贴学习页而非首页或分享链接，并确认课程类型。
- 任务卡住：查看运行页是否等待人工处理；完成页面操作后点击继续。如是普通执行错误，停止后根据日志修正配置再运行。
- 转录失败：核对 ffmpeg、模型下载网络、磁盘空间以及输出目录写权限。
- 定时未启动：检查规则是否启用、时区和时间、应用是否运行，以及账号是否冲突。
- 界面或页面改版问题：通过「关于与帮助」复制诊断信息并打开反馈页，附上复现步骤、错误提示和必要日志。截图与日志发送前检查账号、课程地址和个人信息。

诊断信息只包含版本、构建编号、运行环境、数据库 schema 与加密可用性，不包含账号密码、课程列表、浏览器登录态或用户目录。应用不自动上传诊断信息。

## 多账号、进度与账号维护

课程库由所有账号共享。每个「账号＋课程」组合保存自己的完成位置和最近运行时间，同一组合在不同工作流中共享续学进度。课程详情按账号列出进度；工作流步骤配置显示所选账号的上次位置。掌握度题库继续共享。

运行中的账号不能编辑。修改登录账号、登录方式或跳转地址会清除该账号的旧登录态，下次运行重新登录。更换密码可在编辑时输入新密码；密码留空保留已有值。系统加密不可用时，密码仅在本次应用会话中保留，重启后需重新输入。

被工作流引用的账号不能删除，需先移除对应步骤。删除账号会移除其密码、登录态和学习进度，保留历史运行快照与转录成品。正在执行的课程不能编辑；不同账号执行同一课程不互相阻塞。

## v3 破坏性升级与备份

v3 不导入旧版本数据。首次启动时账号、课程、工作流和学习进度为空，外观、转录等设置恢复默认；模型需要重新准备。旧版目录、旧数据库与原有转录输出原样保留，首次启动说明提供「打开旧数据目录」入口。

新版默认数据目录：Mac 为 `~/Library/Application Support/auto-course-v3`，Windows 为 `%APPDATA%\auto-course-v3`。实际位置以「关于与帮助 → 打开数据目录」为准。

新版目录中，`auto_course.db` 保存账号资料、课程、组合进度、工作流与历史；`account-credentials/<账号ID>.bin` 保存系统加密密码；`account-profiles/<账号ID>/` 保存登录态。不要直接编辑数据库中的账号或步骤关联。

测试用 `--user-data-dir` 仍有效，但必须指向空目录或现有 v3 目录。明确指定旧版本数据库目录时会拒绝启动，不会原地升级；请换用独立目录。

升级或备份前退出应用，备份整个对应版本的数据目录，转录输出目录另行备份。同一机器恢复时先退出应用，再恢复整个新版目录。密码加密依赖当前系统，换电脑后需重新输入。回退旧版时使用保留的旧目录；v3 数据不会反向导入。
